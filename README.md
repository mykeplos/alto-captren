# Cabañas Alto Captren

Sitio web para arrendar las cabañas **Alto Captren**, en Captren (Curacautín, Región de La Araucanía, Chile), a 10 minutos del Parque Nacional Conguillío.

- 🏡 2 cabañas: Cabaña 1 (6 personas) y Cabaña 2 (4 personas)
- 🌐 Español e inglés
- 💬 Reservas por WhatsApp + calendario de disponibilidad (Google Calendar)
